# 🤖 AI Portfolio Assistant

An **AI-powered personal portfolio chatbot** built using **Generative AI and Streamlit**.  
This application intelligently answers questions about my **resume, skills, projects, and experience**, and also includes an **Interview Practice Mode** for HR and technical interview preparation.

This project transforms a traditional resume into an **interactive AI assistant**, making it easier for recruiters and interviewers to understand my profile.

---

## 🚀 Features

### 🧑‍💼 Portfolio Assistant Mode
- Answers recruiter-style questions strictly based on my **resume and portfolio data**
- Explains projects, skills, education, and internships clearly
- Prevents hallucinations by restricting responses to portfolio content only

### 🎯 Interview Practice Mode
- Asks **HR and Technical interview questions**
- Personalizes questions based on my real projects and experience
- Provides **feedback and improved answers** to help with interview preparation
